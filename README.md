# Movie Watchlist Manager

A beginner-friendly Movie Watchlist Manager built using **HTML**, **CSS**, and **Vanilla JavaScript**.

## Features

- Add Movies
- Select Movie Genre
- Give Ratings (1–10)
- Mark Movies as Watched
- Filter by:
  - Genre
  - Watched
  - Not Watched
- Live Statistics
  - Total Movies
  - Watched Movies
  - Not Watched Movies
  - Highest Rating
  - Average Rating

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
